# Инготех — статичный лендинг

Локальная HTML/CSS-версия макета Figma `ZTjHjq6iYB1rBDQvfdGDID`, узел `5748:2742`.
Эталонные изображения секций находятся в `screens`.

## Просмотр

```powershell
node server.js
```

Откройте адрес, который напечатает сервер. По умолчанию используется порт 3000;
если он занят, сервер выбирает следующий свободный.

Макет имеет фиксированную ширину **1440 px** и высоту **9976 px**. На более широком
экране он центрируется, на узком сохраняет исходную геометрию с горизонтальной
прокруткой. Для визуального сравнения используйте окно 1440 px и масштаб 100%.
Адаптивная компоновка, обработчики кнопок, отправка формы и слайдеры в эту версию
не входят. Старый `js/main.js` не подключён.

## Устройство

- `index.html` — все 11 секций; текст остаётся текстом, карточки собраны из элементов.
- `css/fonts.css` — локальные IngoStem и Roboto Mono.
- `css/variables.css` — существующие цветовые переменные.
- `css/base.css` — сброс и контейнер макета.
- `css/sections.css` — геометрия и оформление элементов.
- `public/assets/source` — существующие иллюстрации ×2, отображаемые в половинном размере.
- `public/assets/figma` — недостающие оригинальные элементы из Figma.

`design-reference/figma-reference.jsx` — сохранённый исходный ответ Figma, он не
выполняется браузером. `scripts/build-static.cjs` переводит его в HTML и обычный
CSS, учитывая готовые экспорты из `source`. React, Tailwind и сборщик не нужны.
Повторный запуск этой команды перезаписывает HTML, базовые и секционные стили:

```powershell
node scripts/build-static.cjs
```

## Визуальная проверка

Рендеры каждой секции и всей страницы сохранены в `design-reference/rendered`.
Проверены размеры секций, загрузка изображений и отсутствие ошибок JavaScript.
`scripts/verify-static.cjs` использует установленный в текущей среде Playwright
и сервер на порту 4173. При переносе проекта путь к Playwright нужно заменить
на путь его локальной установки. Различия сглаживания шрифтов между Figma и
браузерами возможны.
