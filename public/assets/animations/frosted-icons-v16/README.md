# Стеклянные пластины — секвенция v16

Готовые кадры для воспроизведения по скроллу: 242 кадра, исходный темп 24 fps,
продолжительность 10,083 секунды. Щит превращается в сердце быстрым поворотом;
в конце сердце выровнено относительно пластин. Цвет соответствует согласованным
экспортам из Figma с повышенной насыщенностью.

| Каталог | Размер кадра | Вес всех 242 кадров |
| --- | --- | --- |
| `webp_1024` | 1024 × 1024 | 10,1 МБ |
| `webp_720` | 720 × 720 | 8,4 МБ |

Каждый файл — отдельное статичное WebP-изображение с прозрачностью и профилем
sRGB. RGB сжат с качеством 90; альфа сохранена без потерь и проверена для всех
кадров. Фон не запечён. Для блока сайта использовать `background: #27292B`.

## Адреса в текущем проекте

Сервер `server.js` отдаёт файлы относительно корня репозитория. Например:

```text
/public/assets/animations/frosted-icons-v16/manifest.json
/public/assets/animations/frosted-icons-v16/webp_1024/frame_0001.webp
/public/assets/animations/frosted-icons-v16/webp_720/frame_0242.webp
```

Шаблоны в `manifest.json` заданы относительно папки этой инструкции. Если
сборщик публикует содержимое `public` как корень сайта, адрес начинается с
`/assets/animations/frosted-icons-v16/`.

## Подключение к скроллу

При прогрессе секции `progress` от 0 до 1 номер кадра вычисляется так:

```js
const frame = 1 + Math.round(Math.max(0, Math.min(1, progress)) * 241);
const variant = 'webp_1024'; // Для облегчённой версии: 'webp_720'.
const name = `frame_${String(frame).padStart(4, '0')}.webp`;
const url = `/public/assets/animations/frosted-icons-v16/${variant}/${name}`;
```

Обратный скролл уменьшает `progress` и воспроизводит те же кадры в обратном
порядке. Предзагружать выбранный вариант разрешения, а не оба сразу. При
перерисовке canvas сначала очищать предыдущий кадр, затем рисовать новый;
для масштабирования учитывать фактический размер canvas и devicePixelRatio.
Перемещение всей композиции к центру экрана задаётся transform контейнера.
Для `prefers-reduced-motion` использовать один статичный кадр.

В этом коммите добавлены ассеты и описание. Подключение секвенции к странице
и управление скроллом выполняются отдельно.
